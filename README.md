
## О проекте

Проект представляет собой статичную веб-страницу, созданную с использованием HTML и Tailwind CSS.

В работе реализована главная секция сайта, навигация, блок с логотипами партнёров и карточки туристических направлений.

## Технологии

- HTML5
- Tailwind CSS
